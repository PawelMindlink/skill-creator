## Format Specs

| Format | Aspect Ratio | Use Case | Safe Zone |
|--------|-------------|----------|-----------|
| Feed (Square) | 4:5 | Main feed, most placements | Keep text/product in center 80% |
| Stories / Reels | 9:16 | Stories, Reels, TikTok-style | Keep key elements in center 60% (avoid top/bottom 15%) |
| Carousel Card | 1:1 | Multi-product, sequential story | Each card must work standalone |

## Ad Anatomies

### Anatomy 1: Review-Based Ad

```
[HOOK — verbatim customer quote or review headline]
[KEY POINTS — 3 bullet benefits, each specific]
[PRODUCT — clean product shot]
[SOCIAL PROOF — star rating, review count, or press quote]
```

**Best for:** GAM Lead Type SOCIAL PROOF, EMOTIONAL  
**Aesthetic:** Raw Native or Native Overlay

### Anatomy 2: Spec Comparison Card

```
[COMPETITOR SPEC / PRICE] vs [IIYAMA SPEC / PRICE]
[Visual: split screen or table]
[VERDICT LINE — one sentence, specific]
```

**Best for:** GAM Lead Type DIRECT CLAIM, COMPARISON  
**Aesthetic:** Studio Void or clean split-screen

### Anatomy 3: Problem-Solution

```
[PROBLEM VISUAL — the pain state]
[TRANSITION — arrow, "vs", or cut]
[SOLUTION VISUAL — the product as relief]
[BENEFIT LINE — specific outcome]
```

**Best for:** GAM Lead Type PROBLEM-SOLUTION, RISK REVERSAL  
**Aesthetic:** Human Element (left) → Studio Void (right)

### Anatomy 4: Offer-Based

```
[PRODUCT + PRICE — dominant]
[GUARANTEE / EXCLUSIVE BADGE]
[CTA — specific action]
```

**Best for:** GAM Lead Type MECHANISM REVEAL, COMPARISON  
**Aesthetic:** Studio Void

## Composition Rules

1. **Clear over Clever** — if you have to explain the visual, it failed
2. **Simple Language** — text overlays: max 5 words per line
3. **One Focal Point** — one thing the eye goes to first
4. **Static → Video Scaling** — design static first; video is the same concept in motion
5. **Rule of Thirds** — product/face at intersection points, not dead center

## Visual Hooks (Pattern Interrupts)

| Hook | When to Use | How |
|------|------------|-----|
| Red Circle (Paint style) | EMOTIONAL, PROBLEM-SOLUTION | Circle the flaw or the key spec |
| Split Screen | COMPARISON, HYBRID | Left = problem/competitor, Right = solution/iiyama |
| Discord/Forum Screenshot | SOCIAL PROOF | Native overlay of peer recommendation |
| Price Tag Dominant | DIRECT CLAIM | Price as the hero element, product secondary |
| Face/Emotion Close-up | EMOTIONAL | Gamer frustration or relief — no product needed |
