# Offer Blueprint Template

This file contains two templates:
1. **Creation Blueprint** — For designing new offers (State 5, Creation mode)
2. **Audit Report** — For diagnosing and improving existing offers (State 5, Audit mode)

Use whichever template matches the session mode. Replace all `{PLACEHOLDER}` values with actual content.
