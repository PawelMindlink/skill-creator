```json
  },

    "what_fails": ["list of approaches that fail"],
    "tone": "description of correct tone"
  },
  "test_plan": {
    "priority_1": "angle type to test first and why",
    "priority_2": "second angle type",
    "timing_notes": "any seasonal or event-based considerations"
  }

```

**Primary mindstates for Polish e-commerce:**

- `Cautious Competence` — wants to make the objectively best decision; fears being wrong
- `Cautious Security` — fears risk (defects, wrong purchase, no recourse)
- `Prevention` — motivated by removing disadvantage, not gaining advantage
- `Promotion` — motivated by aspiration and identity upgrade
